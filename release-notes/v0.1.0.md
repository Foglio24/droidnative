Prima versione di DroidNative.

## Installazione

```bash
sudo apt install ./droidnative_0.1.0_amd64.deb
```

Poi apri **DroidNative** dal menu e segui **Installazione**. Richiede x86_64, Ubuntu 24.04+
o Debian 12+ (e derivate), sessione Wayland.

## Cosa contiene

- Report di compatibilità (distribuzione, kernel/binder, cgroups, GPU e driver, sessione, firewall).
- Installazione guidata di Waydroid dal repository ufficiale, con impronta della chiave verificata.
- Quattro backend GPU: Mesa Native, NVIDIA Accelerated (waydroid-nvidia venus),
  NVIDIA Experimental (nvidia-prolapse), Software Fallback.
- Installazione di waydroid-nvidia v0.2.0-rc7 con hash e commit fissati e verificati.
- Verifica dell'accelerazione sul renderer reale di SurfaceFlinger e della visualizzazione
  sul desktop.
- Gestione APK: analisi, installazione confermata da Android, avvio, rimozione.
- Operazioni amministrative solo tramite polkit e un elenco chiuso di operazioni.

## Limiti noti

- Waydroid non riceve rete se UFW è attivo con criterio DROP: l'app propone le regole minime
  per `waydroid0`, da applicare con conferma.
- Mesa su una iGPU AMD/Intel non può essere mostrato da un desktop che gira sulla GPU NVIDIA:
  DroidNative lo rileva e propone il backend NVIDIA.
- waydroid-nvidia v0.2.0-rc7 è una pre-release upstream; dopo ogni aggiornamento del driver
  NVIDIA va ripetuto il passo GPU.
- Clipboard, notifiche, condivisione file, X11 annidato e ARM64 non sono ancora implementati.

## Verifica

`SHA256SUMS` è allegato; la provenienza di build è verificabile con
`gh attestation verify droidnative_0.1.0_amd64.deb --repo Foglio24/droidnative`.

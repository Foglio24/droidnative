First DroidNative release.

## Install

```bash
sudo apt install ./droidnative_0.1.0_amd64.deb
```

Then open **DroidNative** from the menu and follow **Setup**. Requires x86_64, Ubuntu 24.04+
or Debian 12+ (and derivatives), a Wayland session.

## What it contains

- Compatibility report (distribution, kernel/binder, cgroups, GPU and drivers, session, firewall).
- Guided install of Waydroid from the official repository, with the key fingerprint checked.
- Four GPU backends: Mesa Native, NVIDIA Accelerated (waydroid-nvidia venus),
  NVIDIA Experimental (nvidia-prolapse), Software Fallback.
- Install of waydroid-nvidia v0.2.0-rc7 with pinned, verified hashes and commit.
- Acceleration check against SurfaceFlinger's real renderer, and of the display on the desktop.
- APK management: analysis, install confirmed by Android, launch, removal.
- Administrative operations only through polkit and a closed list of operations.

## Known limits

- Waydroid gets no network when UFW is on with a DROP policy: the app offers the minimal rules
  for `waydroid0`, applied after confirmation.
- Mesa on an AMD/Intel iGPU cannot be shown by a desktop running on the NVIDIA GPU: DroidNative
  detects it and offers the NVIDIA backend.
- waydroid-nvidia v0.2.0-rc7 is an upstream pre-release; the GPU step must be repeated after
  every NVIDIA driver update.
- Clipboard, notifications, file sharing, nested X11 and ARM64 are not implemented yet.

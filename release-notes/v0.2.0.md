## What's new

- **New Material 3 interface**: tonal green palette, system light and dark theme, pill
  buttons, Roboto font and Material Design icons bundled in the package.
- **Real Android app icons** in the app list.
- **Italian and English**: Italian when the session is in Italian, English in every other
  case — for the app, the backend messages, the CLI (`droidnative --help` included) and the
  privileged helper.
- **Install APK** on the overview opens the file picker right away.

## Fixes

- With waydroid-nvidia installed, Mesa Native no longer reports the GPU node set by
  waydroid-nvidia as “to be installed”.

## Install

```bash
sudo apt install ./droidnative_0.2.0_amd64.deb
```

Run it from the folder where you downloaded the file. `SHA256SUMS` is attached; provenance can
be checked with `gh attestation verify droidnative_0.2.0_amd64.deb --repo Foglio24/droidnative`.

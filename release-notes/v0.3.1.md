## Correzioni

- **Android non partiva dopo un riavvio** sui PC con GPU NVIDIA e una seconda GPU (per esempio
  la grafica integrata AMD o Intel). Linux numera le GPU nell'ordine in cui si caricano i
  driver, e l'ordine può cambiare a ogni avvio: waydroid-nvidia salva il numero della GPU
  NVIDIA (`/dev/dri/renderD128` o `renderD129`) solo quando si sceglie la modalità, e il
  controllo all'avvio del container rifiuta il valore rimasto sull'altra GPU.
  - Il nuovo servizio `droidnative-render-node.service` gira prima di ogni avvio del
    container e, in modalità venus, aggiorna il nodo cercando la GPU NVIDIA per produttore
    PCI, poi rigenera la configurazione del container. Non serve nessuna azione.
  - Se il container è già fallito, Installazione → «Avviare il servizio del container» indica
    la causa e lo ripara con un clic; il report di compatibilità e `droidnative session start`
    spiegano il problema invece di attendere fino al timeout.

- L'helper privilegiato ignorava `--lang`: con pkexec i suoi messaggi erano sempre in
  inglese, anche su un sistema in italiano.

## Pubblicazione

- La CI pubblica la release solo dopo aver ricontrollato il pacchetto caricato e riprova
  l'upload in caso di errori temporanei di GitHub (la 0.3.0 era rimasta in bozza per questo).

## Installazione

```bash
sudo apt install ./droidnative_0.3.1_amd64.deb
```

Il comando va lanciato in un terminale, nella cartella in cui hai scaricato il file.
`SHA256SUMS` è allegato; la provenienza è verificabile con
`gh attestation verify droidnative_0.3.1_amd64.deb --repo Foglio24/droidnative`.

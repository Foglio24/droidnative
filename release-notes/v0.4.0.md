## What's new

- **Choice of ARM translator**: besides Google's libndk, Intel's **libhoudini** is now
  available. Some apps run with only one of the two: Age of Empires Mobile, for instance,
  aborts inside libndk and runs with libhoudini. Setup's “ARM translation” step installs the
  one suited to the CPU (libndk on AMD, libhoudini on Intel) and, once active, offers a
  **Use libhoudini** / **Use libndk** button to switch; from a terminal:
  `droidnative arm-translation install --translator libhoudini`. Switching removes the
  previous translator's files and kernel handlers.
- **Mouse as touch** per app (the hand icon in the app list, or
  `droidnative app touch <package> on|off`): for games that ignore mouse clicks, Android
  delivers clicks and drags as touches. It applies the next time the app opens.
- **Windows** (Android apps page, or `droidnative windows single|multi`): *A window per app*
  gives every app its own desktop window, resizable by dragging its edges (Android's PC mode
  with freeform windows). Hold Super and drag to move a window smoothly. Changing the mode
  restarts Android.
- **English** wherever the system language is not Italian, now also for the package
  description and the desktop entry; the documentation on GitHub is in English.

## Good to know

- libndk and libhoudini are proprietary binaries DroidNative downloads, only when you choose
  the step, from third-party archives pinned to a commit and SHA-256. This libhoudini build
  states at startup that it is licensed for Google Play Games on Windows under a commercial
  agreement: using it elsewhere is your call.
- Apps protected by strong anti-cheat or Play Integrity may still refuse to run.

## Install

```bash
sudo apt install ./droidnative_0.4.0_amd64.deb
```

Run it in a terminal, in the folder where you downloaded the file. `SHA256SUMS` is attached;
provenance can be checked with
`gh attestation verify droidnative_0.4.0_amd64.deb --repo Foglio24/droidnative`.

## What's new

- **Google Play**: a new optional “Google services (Play Store)” step in Setup. It downloads
  Waydroid's official GAPPS image (Play Store and Google Play Services) and activates it,
  keeping apps and data; with waydroid-nvidia the GPU mode is re-activated by itself. The
  “Register the device with Google” card shows the device ID, copies it and opens
  google.com/android/uncertified: you register it yourself with your account. From a
  terminal: `droidnative google-id`.
- **ARM-only apps**: a new optional “ARM translation (libndk)” step. It installs Google's
  ARM→x86 translator (third-party archive pinned to commit and SHA-256), Android declares the
  `arm64-v8a` and `armeabi-v7a` ABIs and the APK analysis marks ARM apps as “translated”
  instead of incompatible.
- New commands: `droidnative system-image gapps|vanilla` and
  `droidnative arm-translation install|remove`.
- The compatibility report shows the Google image and ARM translation.

## Fixes

- Switching waydroid-nvidia's mode (`nvidia-mode`) no longer fails when the container was
  started outside systemd (for example by `waydroid init`).

## Good to know

- libndk registers four `binfmt_misc` handlers for ARM executables in the host kernel; while
  installed they take precedence over `qemu-user-static`'s. `droidnative arm-translation
  remove` removes everything, handlers included.
- Apps that require strong Play Integrity (many banking apps, some with DRM or anti-cheat) may
  not work even on a registered device.

## Install

```bash
sudo apt install ./droidnative_0.3.0_amd64.deb
```

Run it from the folder where you downloaded the file. `SHA256SUMS` is attached; provenance can
be checked with `gh attestation verify droidnative_0.3.0_amd64.deb --repo Foglio24/droidnative`.
